# NLP mini-project: bank customer message routing (BANKING77)

Python version: 3.XX (replace with the output of `python --version`)

## Reproduce everything

1. python -m venv .venv
2. Activate it: `.venv\Scripts\activate` (Windows) or `source .venv/bin/activate` (Mac/Linux)
3. pip install -r requirements.txt
4. Open notebook.ipynb in VS Code, select the .venv kernel, then "Run All".
   The data is read from data/train.csv and data/test.csv (BANKING77, PolyAI).
5. The notebook writes results.json and intent_to_team.csv. Seed = 42.
